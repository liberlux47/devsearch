# Django Project Structure: DevSearch

This document provides an overview of the main Python files automatically generated when creating a new Django project.

## Project Structure

```
devsearch/
│
├── manage.py
└── devsearch/
    ├── __init__.py
    ├── asgi.py
    ├── settings.py
    ├── urls.py
    └── wsgi.py
```

## Core Files

### manage.py

`manage.py` is a command-line utility that lets you interact with your Django project in various ways. It's a thin wrapper around `django-admin.py` that sets the `DJANGO_SETTINGS_MODULE` environment variable to point to your project's settings.

```python
# Used for:
# - Running the development server: python manage.py runserver
# - Creating migrations: python manage.py makemigrations
# - Applying migrations: python manage.py migrate
# - Creating superuser: python manage.py createsuperuser
```

> **Warning:** This file is automatically generated and managed by Django. Do not modify this file directly unless you fully understand what you're doing. Incorrect changes could prevent your application from running properly. Most project customization should be done through the appropriate Django settings and commands rather than direct file edits.


### db.sqlite3

SQLite database file automatically created by Django when you run migrations. It stores:

- User accounts and authentication data
- Application models and their relationships
- Session information
- Admin activity logs

This is the default database for development but should typically be replaced with a more robust database (PostgreSQL, MySQL) in production.

## Core Project Folder

### devsearch/__init__.py

Empty file that tells Python to treat the `devsearch` directory as a Python package.

### devsearch/settings.py

Contains the core configuration for your Django project:
- Secret key
- Debug mode
- Installed applications
- Template configuration
- Middleware
- Database configuration
- Authentication settings
- Static file handling
- Internationalization
- Time zone settings

Key sections include:
- `INSTALLED_APPS`: List of all Django applications that are active
- `MIDDLEWARE`: Hooks for request/response processing
- `DATABASES`: Database connection information

### devsearch/urls.py

Defines URL patterns for your Django project, mapping URLs to views:

```python
# Currently only includes:
path('admin/', admin.site.urls)  # Django admin site
```

You'll expand this file to include URLs for your applications as they're developed.

### devsearch/wsgi.py

Web Server Gateway Interface (WSGI) configuration for production deployment. Used by web servers like Gunicorn, uWSGI, or Apache with mod_wsgi to serve your application.

### devsearch/asgi.py

Asynchronous Server Gateway Interface (ASGI) configuration for production deployment with asynchronous capabilities. Used by servers like Daphne or Uvicorn, especially when implementing WebSockets or other asynchronous features.
